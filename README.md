# NullTrace – Feedback Analytics Platform

NullTrace is a full-stack feedback analytics platform built using **React, Next.js, Tailwind CSS, Flask, and PostgreSQL**. The application processes user feedback and uses **TextBlob** for AI-based sentiment analysis.
